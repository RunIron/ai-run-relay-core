# Bundled fallback license notices

Retrieved 2026-10-01 from upstream projects:

- TCL-LICENSE.txt: https://raw.githubusercontent.com/tcltk/tcl/core-9-0-branch/license.terms
- TK-LICENSE.txt: https://raw.githubusercontent.com/tcltk/tk/core-9-0-branch/license.terms

These notices are used when the Python distribution omits its Tcl/Tk notices.
The build additionally copies Python's license and Nuitka's license, runtime exception and notice from the installed compiler distribution.
Relay's noncommercial license does not replace any third-party component's own license.
