# Public Release Notes

This repository contains the public source release of AI Run Relay v0.1.6.

## Scope

The complete source tree is published for non-commercial use under the accompanying license. Commercial use requires prior written permission from the project owner.

## Security boundary

- Do not commit personal SQLite databases, exported work results, Codex configuration, login files, API keys, or other credentials.
- The application is designed for local use and binds its control panel to `127.0.0.1` by default.
- Do not expose the local control panel to the public internet without an independent security review.
- Third-party CLI, MCP, hooks, models, and services remain subject to their own terms and security boundaries.

This document describes release protection and safe usage; it does not restrict the public availability of this repository.
